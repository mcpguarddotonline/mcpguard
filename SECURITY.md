# Security policy

MCP-Guard is security software, so we take reports seriously.

**Report a vulnerability:** email **security@mcpguard.online** with steps to reproduce.
Please do not open a public issue for security problems.

- We acknowledge reports within 2 business days.
- We aim to ship a fix for confirmed high-severity issues within 14 days.
- We credit reporters in the release notes unless you prefer otherwise.

Detection bypasses (a payload that should be caught but isn't) are welcome as
regular issues or pull requests with a failing test in `crates/mcpguard-engine/tests/`.
